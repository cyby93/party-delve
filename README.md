# Repository Starter Docs

This starter set is intended to make Claude immediately useful in a fresh repository.

## Included

- `CLAUDE.md`
- architecture decision record starter
- networking, telemetry, UX, gameplay, and content specs
- phase planning task lists
- role-specific prompt files
- task template

## Suggested setup order

1. Copy `CLAUDE.md` to the repository root.
2. Copy the `docs/` folder into the repository.
3. Copy `TASK_TEMPLATE.md` to the repository root or `docs/agents/`.
4. Start Claude with the Orchestrator prompt.
5. Let Claude produce the first bounded-context task before any implementation.
