# Gameplay Specification

## Purpose

Define the first playable gameplay slice and its design constraints.

## First Playable Slice

The first production-like slice should include:
- 1 lobby flow
- 1 character selection screen
- 2 playable archetypes
- 1 short dungeon run
- 3 enemy types
- 1 miniboss or boss
- 3 to 4 abilities per character
- revive mechanic
- one cooperative synergy or shared objective
- local authority
- baseline telemetry

## Combat Goals

- cooperative readability
- low-friction input from phones
- clear host-side combat feedback
- revive and team-state tension
- stable authoritative resolution

## Character Constraints

The first two archetypes should be easy to tell apart in role, input pattern, and visual feedback.

## Enemy Constraints

The first enemy set should validate:
- basic movement pressure
- readable telegraphs
- target prioritization
- revive pressure

## Validation Goal

The slice exists to validate whether the couch co-op input model, combat loop, and hybrid architecture are both fun and technically stable.
