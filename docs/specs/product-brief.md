# Product Brief

## Working Title
Hybrid Couch Co-op Dungeon Crawler

## Vision

Create a real-time couch co-op action game where one shared host screen shows the game world and each player uses their phone as a lightweight controller.

## Core Fantasy

A group of players survives a compact dungeon run together through movement, abilities, revives, and shared situational awareness on one screen.

## Primary Experience

- one shared screen
- multiple phone controllers
- fast session start
- low-friction local play
- readable co-op combat

## Primary Mode

Local Party Mode is the flagship experience.

## Secondary Mode

Online / Remote Mode extends the same simulation core to internet sessions with latency mitigation.

## Target Outcome

Validate that the input model, co-op loop, and hybrid architecture are fun, stable, and understandable to external playtesters.
