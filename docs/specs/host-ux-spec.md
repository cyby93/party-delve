# Host UX Specification

## Purpose

Define the shared-screen experience so the host display remains the center of attention for all players.

## Core Principles

- The host screen is the primary shared information surface.
- All critical cooperative information should be visible here.
- The screen must remain readable from couch distance.
- The host should clearly communicate session state, player state, and combat clarity.

## Required Screens

- main menu
- lobby
- QR / join code display
- character selection
- in-run gameplay
- pause
- reconnect and player status indicators
- run end / game over

## Shared Information Priority

The host should clearly show:
- player positions
- enemies
- objectives
- loot
- revive opportunities
- boss telegraphs
- team state

## Design Constraints

- avoid clutter
- avoid phone-only details on the host
- use strong hierarchy for critical combat information
- ensure spectators can understand what is happening

## Usability Checks

Every major host UX change should be evaluated for:
- couch readability
- join-flow clarity
- spectator clarity
- reconnect clarity
- combat legibility
